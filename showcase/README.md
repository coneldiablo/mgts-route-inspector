# Интерактивный прототип МГТС

```sh
npm ci
npm run dev
npm run build
npm run preview
```

Публичная витрина показывает три действия в одной карточке ТКШ-014. На осмотре можно назначить работы по двум независимым признакам. На пересъёмке можно указать нужный ракурс и приложить снимок к той же карточке. На приёмке можно сравнить изображения и принять результат по каждому назначенному действию.

Публичные изображения синтетические. Файл пользователя остаётся в текущей вкладке. Решения и учебные кадры сохраняются в браузере. Для инференса на собственных фотографиях используйте [локальный запуск ML](../docs/FINAL.md).

GSAP выполняет короткие переходы и анимацию при прокрутке. При включённом системном уменьшении движения они отключаются. Сборку из `dist/` можно разместить на статическом хостинге.
