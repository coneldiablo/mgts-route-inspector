# Контур · Маршрутный осмотр МГТС

Из каталога `showcase`:

```sh
npm ci
npm run build
npm run preview
```

Vite собирает в `dist/` сайт с базовым путём `/mgts-route-inspector/`. Откройте этот путь на адресе, который напечатает preview. Для разработки используйте `npm run dev`.

Главная содержит учебную карточку ТКШ-014. Мастер отдельно рассматривает механическое повреждение и покрытие, при необходимости запрашивает ракурс, отмечает работы и сверяет контрольный кадр. Состояние учебной карточки сохраняется в браузере. Загруженный в учебную карточку файл доступен только в открытой вкладке. Кнопка под карточкой выгружает текущие решения в CSV.

`predict/` содержит приложение из соседнего каталога `browser-ml`. Оно обрабатывает снимки на устройстве, ведёт карточки и сохраняет реестр рейса. Для чистой копии репозитория сначала подготовьте ONNX и WASM через `../browser-ml/prepare_runtime.sh`, если каталог runtime ещё пуст.

`registry/` содержит обезличенные результаты по 62 снимкам, фильтры и CSV. При сборке Vite берёт опубликованные ресурсы из соседних каталогов `registry`, `browser-ml`, `runs/final-cabinet` и `runs/cabinet-vertex`. Собранный сайт автономен. Раздел Gemini показывает запись завершённого серверного запроса.

Иллюстрации на главной созданы для проекта. Фирменные материалы взяты из брендбука МГТС. При системной настройке уменьшенного движения прокрутка и переходы статичны. На телефоне загружается уменьшенная иллюстрация.
