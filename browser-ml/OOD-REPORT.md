# Проверка предупреждения о нетипичном кадре

Предупреждение исследовали отдельно от оценки качества кадра, распознавания типа шкафа и моделей МП/ЛКП. При фиксированном пороге оно сработало на двух внешних наборах. Частота предупреждений на штатных кадрах менялась между разбиениями, поэтому эксперимент в браузерный осмотр не включён.

## Порог и результаты

Использовали имеющийся DINOv2 INT8 с теми же четырьмя фрагментами кадра. Признак нормировали по L2 и считали наибольшее косинусное сходство с известными примерами. Порог `0.6208919882774353` зафиксирован по второму наименьшему результату основного группового разбиения ДСС (`seed=42`) до оценки внешних изображений. Предупреждение соответствует значению строго ниже порога. Прототипы сравнивали по тому же порогу. Каждый прототип усредняет не менее пяти независимых групп, для оценки OOF прототипы рассчитывали внутри обучающей части каждого фолда.

| Проверка | Ближайший пример | Агрегированные прототипы |
| --- | ---: | ---: |
| Штатные фото ДСС, `seed=42` | 1/61 | 6/61 |
| Штатные фото ДСС, `seed=17` | 1/61 | 4/61 |
| Штатные фото ДСС, `seed=23` | 1/61 | 2/61 |
| Штатные фото ДСС, `seed=71` | 4/61 | 4/61 |

| Железнодорожные шкафы сигнализации из Wikimedia Commons | 11/11 | 11/11 |
| Приближения шести из тех же железнодорожных шкафов | 5/6 | 6/6 |

Доли показывают, сколько кадров получили бы предупреждение. AUROC для ближайшего примера составил 0,994 на постаматах, 0,990 на исходных кадрах шкафов сигнализации и 0,978 на их приближениях. Эти значения сравнивают штатные кадры основного OOF с внешними изображениями, получившими оценки по полному набору эталонов. Фотографии различаются источником, фоном и композицией. Приближения повторно используют шесть изображений и отдельно проверяют вклад фона. Внешние фотографии аналогичных РЩ и ТКШ на новых маршрутах по независимому эталону в этот опыт не входят.

Публичные источники изображений и лицензий указаны в категориях. Кадры отбирались по содержимому до вычисления оценок. Точные идентификаторы файлов и границы приближений зафиксированы в скрипте. ## Воспроизведение локально

Запустите из корня репозитория с Python, `curl` и локальной копией браузерного ONNX. Для полного сравнения нужны локально доступные официальные папки ДСС, выданные организаторами. Скрипт скачивает публичные превью Commons, рассчитывает признаки в памяти и записывает только сводные значения. Фото ДСС остаются на машине.

```sh
python -m pip install -e '.[excel]' 'scikit-learn==1.9.1' onnxruntime
python -m scripts.fetch_public_manholes
python -m scripts.benchmark_cabinet_ood \
  --sources /путь/к/Датасет-ДСС /путь/к/Датасет-ДСС-2 \
  --manhole-holdout data/real_holdout \
  --output /tmp/cabinet-ood-report.json
```
